# ai-
매일 아침 9시에 "AI로 수익을 낼 수 있는 아이디어"를 보고해줘.

[중요 전제]
- 나는 코딩을 잘 모른다. 코딩 지식이 거의 없어도 실행 가능한 아이디어 위주로 찾아줘.
- 전문 용어는 최대한 풀어서 쉽게 설명해줘.

[아이디어 평가 방식]
1. 웹 검색으로 최신 AI 이슈/트렌드를 먼저 조사한다.
2. 그 트렌드에서 파생될 수 있는 수익화 아이디어를 3~5개 제안한다.
3. 각 아이디어마다 다음 항목을 표로 정리한다:
   - 아이디어 점수 (수익화 가능성 + 성장 가능성 기준, 10점 만점)
   - 구현 비용 (대략적인 금액대)
   - 구현 시간 (예상 소요 기간)
   - 난이도 (코딩 지식 거의 없는 사람 기준, 상/중/하)
   - 그리고 내가 여기서 뭘 배울 수 있는지도

- 그다음 아이디어 표
