# ai-
매일 아침 9시에 "AI로 수익을 낼 수 있는 아이디어"를 보고해줘.

[중요 전제]
- 나는 코딩을 잘 모른다. 코딩 지식이 거의 없어도 실행 가능한 아이디어 위주로 찾아줘.
- 전문 용어는 최대한 풀어서 쉽게 설명해줘.

[아이디어 평가 방식]
1. 웹 검색으로 최신 AI 이슈/트렌드를 먼저 조사한다.
2. 그 트렌드에서 파생될 수 있는 수익화 아이디어를 3~5개 제안한다.
3. 각 아이디어마다 인터넷에 있는 정보를 최대한 종합해서, 아래 6가지 기준으로 검증한 뒤 표로 정리한다:
   - **수요 검증**: 수요가 얼마나 있는지(상/중/하), 그 수요를 파악하는 게 얼마나 힘든지(검색·커뮤니티 반응만으로 알 수 있는지, 아니면 직접 설문·인터뷰가 필요한지)와 근거
   - **마케팅 난이도/방법**: 수요가 검증됐다고 가정할 때, 마케팅 난이도(상/중/하)와 구체적으로 어떻게 알려야 하는지(채널·방법 1~2가지)
   - **기술 구현 가능성**: 지금 나(코딩 거의 모름) 수준에서 노코드/AI 도구로 구현 가능한지, 필요한 도구는 무엇인지
   - **예상 비용**: 초기 비용 + 매달 운영 비용 대략치
   - **AI 활용 시 소요 시간**: AI를 최대한 활용했을 때 시작부터 런칭까지 걸리는 대략적인 기간
   - **활용 가능한 AI 스킬/플러그인/도구**: 실제로 사용할 수 있는 AI 도구·플러그인 이름을 구체적으로 (예: Claude, ChatGPT, Perplexity, Make, Zapier, 노코드 빌더 등)

[출력 형식]

- 그다음 6가지 검증 기준이 모두 담긴 아이디어 표
- 마지막에 그 중 가장 추천하는 아이디어 1개와 이유
